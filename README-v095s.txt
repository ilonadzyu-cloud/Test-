v0.9.5s
- Відновлено видимість персонажів у сюжетних сценах. Правило лишається: максимум 2 діючі особи в кадрі.
- Євпапій більше не ховається глобальним CSS. Якщо він прописаний як один із двох акторів сцени, він показується.
- Те саме правило працює для інших персонажів: патч не видаляє діючу особу просто через її роль.
- У видимому UI «ГЕРОЙ/Герой» замінюється на «ВИ/Ви» для більшого погруженія.
- Звичайної цибулі більше нема: item id onion тепер називається «Дивна цибуля».
- До першого реального використання часник, дивна/зла/вонюча цибуля та невідоме зілля лежать у «Якась хуйня» з описом «???».
- Після реального використання в сюжетному бою конкретна цибуля або часник відкривається як «Зброя» і отримує нормальний опис.
- Часник після відкриття: «ТРУПОСМЕРДу дуже не подобається.»
- Невідоме зілля лишається у «Якась хуйня», поки його функція сюжетно не розкрита.
